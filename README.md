This repository contains code for the hypothalamus AD-BXD project, where we characterized several signatures of the 5XFAD transgene within the hypothalamus; several associations were conserved in analysis of human AD patients vs controls. 

The structure of the code is organized by: 1) prepro/QC/clustering/atlas creation 2) shared analyses relevant to multiple figures; or 3) analyses that are only relevant to one figure. 

Some caveats: For clustering, I included the code to sub cluster VLMCs as a representative example of the approach used, which was similar across cell classes. Given data sharing regulations, we are unable to share raw data/metadata for the human hypoAD/Rosmap MB datasets (located on Synapse).

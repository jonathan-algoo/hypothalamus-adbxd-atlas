This repository contains code for the manuscript titled "Linking Molecular Changes in the Hypothalamus to Alzheimer’s Disease Phenotypes". We identified cell-type specific changes to the primary brain region that controls homeostsis, the hypothalamus, in a genetically diverse Alzheimer's model (the AD-BXDs). Several associations, including neuroinflammatory signatures, were replicated in human AD patients. 

Counts matrices and animal metadata, alongside intermediate data objects used in analysis and another copy of the code, are located on Hugging Face at the following link: . Processed data is also available for download or exploration on the CZI Cell x Gene Explorer at https://cellxgene.cziscience.com/collections/7039e317-12d2-424a-8ea6-479d6e7a8cf0. 

Given data sharing regulations, we are unable to share raw data/metadata for the human hypoAD/Rosmap mammillary body datasets, which were used for replication (analyses of Figure 7).
